## 4. 화면 공통 상태 규칙

`AGENTS.md` 완료 기준(로딩·빈·오류·비활성·중복 실행 방지)을 이 프로젝트 화면에 적용한 규칙이다. 화면마다 아래를 모두 구현해야 완성으로 본다.

| 상황 | 규칙 |
| --- | --- |
| 로딩 | `Skeleton`. <예외 화면이 있으면 적는다> |
| 빈 상태 | 화면별 문구를 고정한다: <화면 — "문구"> |
| 오류 | `ApiError.code` 로 분기해 `features/<domain>/errors.ts` 의 문구를 쓰고 재시도 버튼을 둔다. 401 은 토큰 갱신 후 1회 재시도, 실패 시 로그인 |
| 중복 실행 | 돈이 움직이는 요청은 `isPending` 동안 버튼 비활성 + 같은 요청 단일 실행 |
| 오프라인·타임아웃 | 조회 10초, 돈이 움직이는 요청 30초(`api/client.ts` 상수). 타임아웃은 재시도 가능한 폴백 |
